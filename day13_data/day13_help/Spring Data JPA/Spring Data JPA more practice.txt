4.17 Find all diagnostic tests prescribed in an appointment
i/p - Appointment id
//Hint - Appointment *--->* diagnosticTests : DiagTest
In AppointmentRepo
- 
In AppointmentService - Set |List dto
-@Service @Transactional
Appointment appointment=appointmentRepo.findById orElseThrow(...);
return appointment.getDiagnosticTests() //Set<Entity>
.stream() //Stream<Entity>
.map(entity -> modelMapper.map(entity,dto.class)) //Stream<DTO>
.toSet(); //Set <DTO>

OR 

Custom query - Find all diagnostic tests prescribed in a given appointment
@Query("select t from Appointment a join a.diagnosticTests t where a.id=:aid")
Set<DiagTest> getDiagnosticTestsForAppointment(@Param ("aid")Long appointmentId))
